Les trois programmes suivants illustrent des notions de base du langage C. Compile-les et ajoute une capture de leur exécution dans ton portfolio.

Programme 1 — Pair ou impair

Notions : variable, lecture, condition et opérateur modulo.

#include <stdio.h>
int main() {
    int n;
    printf("Donner un entier : ");
    scanf("%d", &n);
    if (n % 2 == 0)
        printf("Pair\n");
    else
        printf("Impair\n");
    return 0;
}

Explication : le reste de la division par 2 permet de savoir si le nombre est pair.

Programme 2 — Somme de 1 à N

Notions : boucle for et accumulateur.

#include <stdio.h>
int main() {
    int n, i, somme = 0;
    printf("Donner N : ");
    scanf("%d", &n);
    for (i = 1; i <= n; i++)
        somme = somme + i;
    printf("Somme = %d\n", somme);
    return 0;
}

Explication : la variable somme mémorise progressivement le total des entiers.

Programme 3 — Maximum d'un tableau

Notions : tableau, boucle et comparaison.

#include <stdio.h>
int main() {
    int t[5], i, max;
    for (i = 0; i < 5; i++) {
        printf("t[%d] = ", i);
        scanf("%d", &t[i]);
    }
    max = t[0];
    for (i = 1; i < 5; i++) {
        if (t[i] > max)
            max = t[i];
    }
    printf("Maximum = %d\n", max);
    return 0;
}

Explication : on initialise le maximum avec le premier élément, puis on le met à jour si un élément plus grand est trouvé.
