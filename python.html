Projet 1 — Calculatrice simple

Problème : effectuer une opération entre deux nombres.

def calculatrice():
    a = float(input("Premier nombre : "))
    op = input("Operation (+, -, *, /) : ")
    b = float(input("Deuxieme nombre : "))
    if op == "+":
        print(a + b)
    elif op == "-":
        print(a - b)
    elif op == "*":
        print(a * b)
    elif op == "/" and b != 0:
        print(a / b)
    else:
        print("Operation impossible")

calculatrice()

Fonctionnement : le programme lit deux nombres et un opérateur, puis choisit le calcul avec des conditions.

Difficulté à documenter : gérer la division par zéro et les opérateurs non reconnus.

Projet 2 — Jeu de devinettes

Problème : trouver un nombre choisi aléatoirement.

from random import randint

secret = randint(1, 20)
reponse = 0
while reponse != secret:
    reponse = int(input("Devine le nombre entre 1 et 20 : "))
    if reponse < secret:
        print("Plus grand")
    elif reponse > secret:
        print("Plus petit")
print("Bravo !")

Fonctionnement : une boucle continue jusqu'à ce que la réponse soit égale au nombre secret.

Difficulté à documenter : éviter les saisies qui ne sont pas des nombres.

Projet 3 — Gestionnaire de notes

Problème : calculer la moyenne d'une liste de notes.

notes = []
n = int(input("Nombre de notes : "))
for i in range(n):
    note = float(input("Donner une note : "))
    while note < 0 or note > 20:
        note = float(input("Note invalide, recommencer : "))
    notes.append(note)

if n > 0:
    moyenne = sum(notes) / n
    print("Moyenne :", moyenne)

Fonctionnement : les notes sont stockées dans une liste, validées entre 0 et 20, puis leur moyenne est calculée.

Difficulté à documenter : traiter le cas où le nombre de notes vaut zéro.
