# Portfolio numérique — Eya

## Structure
- `index.html` : accueil et liens vers les 8 modules
- `style.css` et `script.js` : style et fonctionnalités partagés
- `digital-skills/` : cybersécurité, prompt engineering, création de contenu
- `developpement/` : Python, langage C, algorithmique
- `systemes/` : systèmes d'exploitation, architecture et électronique
- `medias/` : déposer ici tes images, PDF, audio et vidéos

## Installation
1. Décompresser le dossier.
2. Ouvrir le dossier dans VS Code.
3. Ouvrir `index.html` avec Live Server ou un navigateur.
4. Tester les 8 cartes de la page d'accueil.
5. Pour GitHub Pages, envoyer tout le contenu du dossier dans le dépôt, en conservant les noms et l'organisation.

## À personnaliser avant le rendu
- Vérifier les informations personnelles et la filière.
- Ajouter ton adresse e-mail au lien `mailto:`.
- Ajouter tes captures d'écran et tes productions réelles dans `medias/`.
- Remplacer les exemples de code par tes propres travaux si nécessaire et vérifier qu'ils fonctionnent.
- Ajouter les résultats et captures réels des trois tests de prompts.
- Compléter la fiche Transparence IA avec les outils réellement utilisés.
- Relire et vérifier les sources et les consignes de l'enseignant.

## Publication GitHub Pages
Dans le dépôt GitHub : Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
L'adresse dépend du nom du compte et du dépôt, par exemple `https://nom-utilisateur.github.io/nom-du-depot/`.
